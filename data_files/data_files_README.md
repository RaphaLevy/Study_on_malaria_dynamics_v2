All files in this folder are regard data collection and treatment.

- data/:
    - sivep_notification_data/: Contains original .parquet and treated .csv files of cases of infection by malaria obtained from SIVEP
    - climate_api_data_2016_2024.csv: Contains climatic data obtained from the Mosqlimate datastore [https://api.mosqlimate.org/api/docs#/datastore/datastore_api_get_copernicus_brasil](https://api.mosqlimate.org/api/docs#/datastore/datastore_api_get_copernicus_brasil)
